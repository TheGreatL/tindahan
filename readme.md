Tindahan is a application for sari sari store owners.

Features:
    1. Customer Loan Tracking
    2. Customers Order
    3. Sales Tracking.
    4. Stock Management
    5. Product Item Tracking
    6. ORCR receipt input.
    7. Bar code Scanner.
    8. Price profit

Tools
    Frontend: React
    Backend: FastAPI
    Database: Mysql
